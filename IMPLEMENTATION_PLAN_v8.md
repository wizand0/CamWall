## Задача 1. Совместимость с 16 KB (диалог при запуске)

**Диагноз.** `libimage_processing_util_jni.so` поставляет `androidx.camera:camera-*:1.3.4`.
В CameraX 1.3.x нативные библиотеки собраны без 16 KB-выравнивания. Исправлено
 upstream в CameraX 1.4.0+ (библиотеки пересобраны с `-Wl,-z,max-page-size=16384`).

**Варианты:**
- **A (рекомендуется).** Поднять CameraX `1.3.4 → 1.4.x` (последний стабильный 1.4).
  Это ЕДИНСТВЕННОЕ изменение версий в плане; без него диалог не убрать.
  API CameraX 1.4 обратно совместим для нашего использования (camera2/lifecycle/view
  + ProcessCameraProvider), миграций не требуется.
  ⚠️ Требуется явное разрешение, т.к. действует запрет на смену версий зависимостей.
- **B (без смены версий).** Оставить как есть. Диалог показывается только на
  16 KB-устройствах и только для debug/несовместимых сборок; на работу не влияет.
  Для публикации в Google Play (требование действует с 01.11.2025) вариант B
  не подходит — придётся делать вариант A до релиза.

Проверка варианта A: `.\gradlew.bat assembleDebug`, затем на устройстве диалог
не появляется; дополнительно — `unzip -l app-debug.apk` + проверка выравнивания
`llvm-objdump`/`zipalign -c -P 16` (достаточно отсутствия диалога на телефоне).

## Задача 2. Night mode по расписанию

**Текущее состояние (проверено в коде).** `SettingsScreen` → Switch →
`SettingsDataStore.NIGHT_MODE_ENABLED_KEY` → `MainActivity` читает Flow из
DataStore и передаёт `darkTheme` в `CamWallTheme`. Проверить на устройстве:
включить ползунок → тема сразу становится тёмной. Это и есть night mode.

**Что делаем:**
1. Новые ключи в `SettingsKeys`:
   - `NIGHT_MODE_START_KEY` (int, минуты от полуночи, по умолчанию 22:00 = 1320);
   - `NIGHT_MODE_END_KEY` (int, минуты от полуночи, по умолчанию 07:00 = 420).
2. `SettingsScreen`:
   - под ползунок Night Mode добавить выбор времени начала и конца
     (два компактных кликабельных поля с `TimePicker` из Material3;
     новые зависимости не нужны — уже есть compose material3);
   - поддержка интервала через полночь (start > end означает
     «с 22:00 до 07:00»).
3. `MainActivity`:
   - эффективная тёмная тема = `nightModeEnabled && nowWithinInterval(start, end)`;
   - пересчёт по тикам раз в минуту (`delay(60_000)` в цикле сбора) + мгновенный
     пересчёт при изменении настроек. Никаких фоновых будильников/WorkManager
     для этого не нужно — батарея не тратится, переключение происходит пока
     приложение открыто (и при следующем открытии).
4. Методы ViewModel: `getNightModeStart()/setNightModeStart()`,
   `getNightModeEnd()/setNightModeEnd()` (по образцу существующих).

**Критерий приёмки:** включить Night Mode, поставить интервал, включающий
текущее время, — тема тёмная; поставить интервал вне текущего времени —
светлая; переход через границу интервала происходит в течение минуты без
перезапуска.

## Задача 3. Ползунок «Фоновое автообновление» + описания

1. Новый ключ `BACKGROUND_UPDATE_ENABLED_KEY` (boolean, по умолчанию `true`).
2. `SettingsScreen` — новый ползунок вверху списка:
   - **Вкл** (текущее поведение): `CameraUpdateManager.scheduleCameraUpdates()`
     активен, периодическая задача WorkManager обновляет кадры в фоне.
   - **Выкл**: `CameraUpdateManager.cancelCameraUpdates()` — фоновые обновления
     полностью отменяются; секция Night Mode становится серой и неактивной
     (по требованию пользователя: нет фона — night mode не имеет смысла).
   - При старте приложения (`CamWallApplication`/`MainActivity`): если флаг
     выключен — периодическая задача не планируется.
3. Короткие описания под ползунками (тексты согласовать):
   - Фоновое автообновление: «Периодически обновляет кадры камер в фоне
     (минимум раз в 15 минут — ограничение Android). Отключите, чтобы
     сэкономить батарею и трафик.»
   - Night Mode: «Тёмная тема по расписанию. Автоматически включается
     в заданное время, чтобы меньше расходовать батарею на AMOLED-экранах.»
4. Состояние ползунков и доступность секции Night Mode — через `enabled`
   у composables + `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`
   для «серого» вида.

**Критерий приёмки:** выключить ползунок → в logcat больше не появляются
запуски `CameraUpdateWorker` по расписанию (проверить через 15+ минут или
кнопкой диагностики после повторного включения); секция Night Mode серая
и не реагирует на нажатия; включить обратно → работа восстанавливается.
