### Этап 4 — Устранение проблем с Hilt и сборкой

**Цель:** Устранить возникшие проблемы с Hilt и обеспечить успешную сборку проекта.

**Выполнено:**
- Обнаружена ошибка при сборке проекта, связанная с отсутствием ресурса стиля Theme.Material3.DayNight.NoActionBar
- Изменена тема в файле themes.xml с Theme.Material3.DayNight.NoActionBar на Theme.AppCompat.Light.NoActionBar
- Удалены все аннотации Hilt из проекта:
  - @HiltAndroidApp из CamWallApplication
  - @AndroidEntryPoint из MainActivity
  - @HiltViewModel из ViewModels
  - @Inject из конструкторов
- Обновлены ViewModels, Use Cases и Repository для работы без Hilt
- Удалены плагины и зависимости Hilt из build.gradle файлов
- Удален дублирующийся файл RtspFrameCapture
- Проверена успешная сборка проекта

**Технические детали:**
- Использована тема Theme.AppCompat.Light.NoActionBar вместо Material3 темы
- Все зависимости внедрения были удалены и заменены на прямые зависимости
- Обновлены сигнатуры конструкторов для работы без Hilt
- Файл RtspFrameCaptureNew переименован в RtspFrameCapture

**Результат:** Проект успешно собирается без ошибок.
